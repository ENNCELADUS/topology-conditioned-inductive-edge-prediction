\section{Introduction}
\label{sec:intro}

Link prediction is often evaluated as a collection of independent binary
decisions. This framing is incomplete when the predictions are later assembled
into a graph. A scorer can rank individual pairs well while producing implausible
degree, clustering, density, or spectral structure after thresholding. Edge-level
quality therefore does not establish assembled-graph quality.

The difficulty is sharper under a fully inductive protocol. Both queried
endpoints are unseen during training, neither has an observed incident edge, and
the predictor receives exactly the frozen endpoint features $(x_u,x_v)$. Methods
that extract query subgraphs, paths, or common neighbors from an observed graph
cannot be applied without changing that input contract. Conversely, direct
feature-pair scorers respect the contract but make no explicit use of the
structural regularities learned from $G_{\mathrm{train}}$.

We study \textbf{topology-conditioned inductive edge prediction}: binary edge
classification in which training-graph structure supervises an intermediate
query-local topology representation. The representation is inferred from the two
endpoint features and supplies context for deciding $\operatorname{edge}(u,v)$;
it is not an additional task input and is not itself the prediction target. The
mechanism used to represent that context remains an empirical question. We
compare latent, deterministic, generative, and optional retrieval-supported arms
under the same strict endpoint-only contract.

The formulation follows two principles. First, topology must help the queried
edge decision rather than merely repair a graph after independent scoring.
Second, evaluation must report edge and assembled-graph behavior together. We
therefore score a fixed pair universe once, assemble $\widehat G_\tau$, and report
edge metrics alongside GS, RD, and the degree, clustering, and spectral MMD
ratios. These measurements remain separate because each captures a different
failure mode.

\paragraph{Contributions.}
\begin{enumerate}
    \item We formalize fully inductive, zero-observed-edge prediction with exact
    task input $(x_u,x_v)$ and query-local topology as intermediate context.
    \item We characterize the pair-to-topology gap through joint edge-level and
    assembled-graph evaluation.
    \item We compare topology representations under a shared protocol while
    keeping retrieval support explicitly separate from the task definition.
    \item We evaluate credible simpler explanations, including direct pair
    scoring, loss shaping, retrieval-only support, and post-hoc denoising.
\end{enumerate}
