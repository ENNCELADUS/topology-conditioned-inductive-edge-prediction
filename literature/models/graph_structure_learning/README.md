# GSL Folder Map

- `surveys_benchmarks/`: GSL surveys and benchmark papers.
- `latent_structure_learning/`: Methods for learning latent adjacency, edge weights, topology, or graph distributions.
- `denoising_robust_sparsification/`: Methods for graph denoising, robustness, edge pruning, and sparsification.
- `self_supervised_structure_learning/`: Self-supervised methods for graph structure refinement or structure-aware representation learning.
- `pooling_hierarchy_subgraph/`: Pooling, hierarchy, clustering, and subgraph representation methods.
- `community_graph_modules/`: Community detection and graph module papers.
- `masked_autoencoding/`: GAE, masked GAE, masked-edge reconstruction, and graph masked modeling papers.
